# Portfolio - Jefferson Goncalves

Portfolio profissional para divulgacao de servicos em **Desenvolvimento Web**, **Design Grafico** e **UI/UX Design**.

## Sobre

Site portfolio responsivo e moderno com multiplos temas (Dark, Light, Lux), animacoes suaves e secoes organizadas para captacao de clientes.

## Secoes

- **Hero** - Apresentacao com foto de perfil, typing effect e links sociais
- **Sobre** - Informacoes pessoais, experiencia e download de CV
- **Servicos** - Desenvolvimento Web, Design Grafico, UI/UX Design
- **Habilidades** - Barras de progresso animadas para skills tecnicas e de design
- **Projetos** - Dividido em 4 categorias com filtros:
  - Projetos Clientes
  - Projetos Academicos e Pessoais
  - Design Grafico e UI/UX
  - Jogos
- **Certificados** - Galeria de certificacoes profissionais
- **Contato** - Formulario, email, WhatsApp e redes sociais

## Tecnologias

- HTML5 semantico
- CSS3 com Custom Properties e animacoes
- JavaScript vanilla (ES6+)
- [AOS - Animate On Scroll](https://michalsnik.github.io/aos/)
- [Font Awesome 6](https://fontawesome.com/)
- [Google Fonts - Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)

## Temas

- **Dark Mode** - Tema escuro padrao
- **Light Mode** - Tema claro
- **Lux Mode** - Tema luxo com tons dourados

## Como Usar

1. Clone o repositorio
2. Abra `index.html` no navegador
3. Personalize:
   - Substitua as imagens na pasta `image/`
   - Atualize os links de redes sociais (LinkedIn, GitHub, Behance, Instagram, YouTube)
   - Atualize o email e telefone de contato
   - Adicione seus projetos, certificados e informacoes pessoais

## Personalizacao

Os placeholders estao marcados com comentarios HTML `<!-- INSIRA ... -->` para facilitar a localizacao dos campos que precisam ser preenchidos:

- Logo
- Foto de perfil
- Imagens de projetos
- Imagens de certificados
- Links de redes sociais
- Email e telefone
- Descricoes de projetos

## Responsividade

O site e totalmente responsivo para:
- Desktop (1200px+)
- Laptop (1024px)
- Tablet (768px)
- Mobile (480px)
